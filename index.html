Embed in Google Slides

Google Slides does not natively embed arbitrary webpages via iframe without a helper, so use one of these two clean methods:

  1. Live Embed Extension (Recommended): Host this single HTML file (e.g., GitHub Pages, Netlify, or Vercel), install the free Slides Timer or Live Web Chrome extension, and paste your hosted URL directly onto your slide.
  2. Direct Slide Link: Select any shape or text box on your slide, press Ctrl+K / Cmd+K, and link to your hosted timer URL to launch it cleanly during your presentation.
Shortcuts: Space Start/Pause • R Reset • Click numbers anytime to edit.
